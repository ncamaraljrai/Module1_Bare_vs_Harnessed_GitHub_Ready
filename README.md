# Module 1 — Bare vs. Harnessed: Ablation Experiment

This package is a rubric-aligned submission kit for the public repository:

`https://github.com/ncamaraljrai/foundations_lab01_url_shortener`

## Use these files
- `TASK.md` — immutable task and experiment controls
- `AGENTS.md` — full minimal harness for Run 2 and final submission
- `AGENTS_ABLATED.md` — Run 3 only; verification feedback removed
- `EXPERIMENT_RUNBOOK.md` — exact three-run procedure
- `DIAGNOSTIC_LOG.md` — grader-facing evidence and reflection
- `SUBMISSION.md` — final rubric and publishing checklist

## Important integrity rule
The experiment itself cannot be fabricated. Complete the three fresh runs and replace every `RECORD` field with observed evidence before pushing the submission files to GitHub.
